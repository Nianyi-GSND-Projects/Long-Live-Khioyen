AI Tools Used
 Tripo AI
 https://www.tripo3d.ai/
  Purpose: 3D model generation
  How it was used: Provided text & image prompts to generate base 3D models, which were then imported into Blender and Unity for further modified.
  Output location:
   Assets/Resources/Models/Buildings/PolishedBuildings

 NovelAI
 https://novelai.net/
  Purpose: Character illustrations and 2D artwork
  How it was used: Generated character art and illustrations via text prompts describing character appearance and style. Outputs were edited in Photoshop.
  Output location:
   Assets/Resources/Sprite/Character
   Assets/Resources/Sprite/CG

 Google Gemini
 https://gemini.google.com/
   Purpose: UI and sprite generation
   How it was used: Provided text prompts describing desired UI layout and sprite styles. The generated images were edited for use in the project.
   Output location:
    Assets/Resources/Textures/UI/Icons
    Assets/Resources/Sprite/UI
    Assets/Resources/Sprite/Battle/Battalion
